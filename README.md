# Coffee variety outweighs associated tree identity in shaping disease incidence and fruit load in a large-scale Ugandan Robusta agroforestry system

## Repository description

### Folders

`code` : contain three scripts for Incidence model, fruit load model and map creation

`data` : Contain shape files for maps and `R_PhD_Data_corrected2.xlsx`excel file that contain all the data needed

`output` : A file if you need to save environment

`results` : Were all the figures are saved

### How to use it

If yo don't now how to use git just click on :

1. Code
2. download to zip

![](screen_shot.png)

Then you can run each scripts independently and all the figures will be produced in `results\figures`
